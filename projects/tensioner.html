Dynamic Wire Tensioner

Closed-loop, load-cell based wire tension control for the CNC hotwire cutter — ESP32, PID and a custom PCB.

ESP32 + FreeRTOS Load cell feedback PID motor control KiCad PCB

Overview

This dynamic wire-tensioner is a closed-loop add-on for my CNC hotwire cutter. Instead of relying on fixed weights or manual springs, it continuously monitors wire tension using a precision load cell and automatically adjusts a stepper-driven take-up spool to keep tension stable as the wire heats, cools and stretches during cuts.

An ESP32 runs dual-core FreeRTOS tasks: one core is dedicated to fast, filtered weight readings, while the other handles the PID control loop and stepper drive. A small OLED on the front panel shows startup checks, IP address and live status. A web dashboard provides full control: you can enable the motor, start and stop the controller, see live tension in grams and tune all parameters from a browser.

I used this project as an excuse to go end-to-end: from the first breadboard prototype and AI-assisted firmware experiments through to a fully designed PCB in KiCad, 3D-printed housings and a neat, repeatable wiring harness that bolts straight onto the hotwire machine.

My contributions

  • Full CAD design of the tensioner module: brackets, spool, load cell mounts and enclosure.
  • 3D printing and iterative prototyping of all mechanical parts until the motion felt smooth and rigid.
  • Electronics design in KiCad: custom PCB for ESP32, HX711 (or equivalent amplifier), stepper driver, OLED and connectors.
  • Firmware development on the ESP32 with FreeRTOS tasks for fast tension sampling and motor control.
  • Implementation of a PID loop to keep wire tension inside a configurable dead-band window.
  • Design and build of the browser-based dashboard for live telemetry, control and calibration.
  • On-rig testing with the CNC hotwire cutter: tuning PID, dead-band and safety limits under real cutting loads.
  • Documentation of wiring, calibration steps and integration so the tensioner can be replicated or serviced later.

Electronics & hardware

  • Controller: ESP32 development board mounted on a custom KiCad PCB.
  • Load cell: Compression load cell bolted inline with the wire path.
  • Signal chain: Instrumentation amplifier / HX711 module feeding the ESP32 ADC.
  • Actuator: NEMA 17 stepper motor driving a wire take-up spool via a stepper driver.
  • Display: 0.96″ I²C OLED for local status, tension readout and IP address.
  • Networking: Wi-Fi (ESP32) hosting the REST/WebSocket interface and dashboard.
  • Power: Shared 24 V rail for the stepper with local regulation down to 5 V / 3.3 V for logic.
  • Mechanics: 3D-printed mounts, spool and cable guides, designed to bolt onto the existing hotwire frame.

How the control system behaves

When you start the system from the web app, the controller begins reading wire tension every few milliseconds. Each cycle it:

  • Samples the load cell, filters the reading and converts it into grams of tension.
  • Compares the live value against the target tension and dead-band window.
  • If the tension is inside the window, it does nothing and holds the current motor position.
  • If the tension drifts high or low, the PID controller calculates a correction and steps the motor to wind or unwind wire until tension comes back into range.

This happens continuously, thousands of times per second, so the wire stays stable even as gantries move and foam geometry changes the load. The motor is always disabled by default and must be explicitly enabled from the dashboard. If you stop the system or switch to “motor free” mode, the driver is released immediately so you can move the wire by hand without fighting the motor.

Calibration & web dashboard

All configuration is done through a simple web UI served directly from the ESP32. From the calibration view you can:

  • Adjust PID gains (Kp, Ki, Kd).
  • Set upper and lower limits for motor drive to avoid over-travel.
  • Change the dead-band width (how much tension variation is allowed before any correction happens).
  • Tare the load cell and perform a full calibration with a known weight.
  • Dial in a new target tension and see how the system responds in real time.

The dashboard itself shows live tension in grams, the current target, motor enable state, whether the controller is running or stopped, and a progress bar indicating how close the wire is to the requested tension. All settings are stored in non-volatile memory so the unit remembers its configuration between power cycles.
