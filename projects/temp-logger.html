Temperature Logger

Four-channel SD-card temperature logger for motor, ESC and airflow testing on UAV projects.

Overview

This is a simple but surprisingly useful four-channel temperature logger built around an Arduino, DS18B20 digital temperature probes and an SD card. It was developed for flight testing ENDURA UAV where we needed to track motor, ESC, battery and ambient temperatures over time while experimenting with different props, ducts and cooling layouts.

Every two seconds the logger samples all four DS18B20 sensors and appends a comma-separated line to log.txt on the SD card:

T1,T2,T3,T4 (in °C)

There’s no built-in clock or UI — the device just boots, confirms the SD card is healthy using simple beep codes, waits a few seconds for you to get ready, and then starts logging until power is removed. A small “marker” line (*,*,*,*) is written at the top of each new log to make it easy to split separate runs later.

To turn the raw text logs into something graphable, I built a companion tool, Temp Analyzer (demo). You drag and drop the log.txt file from the SD card into the browser, choose the test date, and the tool automatically separates each test and exports a clean CSV/Excel file ready for plotting or further analysis.

What I did

  • Designed and wired the four-channel temperature logging system around DS18B20 sensors.
  • Implemented SD card logging on an Arduino, including basic fault handling and beep feedback.
  • Created a minimal “headless” workflow: power on, audible confirmation, automatic logging, and safe shutdown by simply removing power when the test is done.
  • Deployed the logger on ENDURA to track motor, ESC, battery and ambient air temperatures during flight tests.
  • Used the data to refine cooling layouts, ducting and airflow around high-load components.
  • Built the browser-based tool to read log.txt, apply timestamps and export the data to CSV/Excel.
  • Documented the wiring convention and channel mapping so the same logger can be reused on future rigs.

Electronics & hardware

  • Microcontroller: Arduino-compatible board (e.g. Arduino Uno / Nano).
  • Temperature sensors: 4 × DS18B20 digital temperature probes (each on its own OneWire pin: D2–D5).
  • Bus wiring: Individual OneWire buses with appropriate pull-up resistors (typically 4.7 kΩ per channel).
  • Storage: SD card module and a micro-SD card formatted as FAT/FAT32.
  • Audio feedback: Piezo buzzer for beep codes.
  • Power: 5 V straight from the flight controllers servo rail.
  • Enclosure / mounting: Small 3D printed box.

How it works & beep codes

On startup the logger runs through a very small sequence of checks and signals its status via the buzzer:

  • SD card initialisation: The firmware calls SD.begin() on the configured CS pin. If this succeeds, it opens log.txt and writes an initial marker line *,*,*,* to separate this run from any previous data.
  • Power-on confirmation: A single longer beep indicates that the SD card mounted correctly and the log file is ready.
  • Logging start: After a 5 second delay (to give you time to start a test, hit record on a camera, etc.), the logger emits two short beeps and begins sampling.
  • Normal logging loop: Every cycle it requests temperatures from all four DS18B20s, prints them to the serial monitor and appends a line to log.txt in the format temp1,temp2,temp3,temp4, followed by a newline.

If anything goes wrong with the SD card, the logger makes it obvious:

  • SD card failure on boot: If SD.begin() fails, the logger enters an infinite loop and emits a repeating pattern of single short beeps with short pauses in between — a continuous alarm that something is wrong with the card or wiring.

When you’re done, you simply power the logger down, pull the SD card, and move log.txt to your computer for analysis.
